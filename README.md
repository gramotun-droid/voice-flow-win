# VoiceFlowWin

Голосовой набор текста для Windows: текст появляется прямо в активном поле
ввода во время речи, а после паузы фраза перепроверяется локальной моделью
Whisper и аккуратно исправляется.

Приложение задумано как замена системной диктовке macOS для Windows 10 и 11.
Распознавание выполняется полностью на компьютере — интернет нужен только для
первоначальной загрузки моделей и проверки обновлений.

## Как это работает

```text
Микрофон → WASAPI → PCM 16 kHz mono 16 bit → кольцевой буфер
                                              ├→ Vosk  → потоковый текст → overlay
                                              └→ VAD   → пауза → Whisper → фраза → поле ввода
```

Две модели решают две разные задачи. **Vosk** даёт текст с задержкой в доли
секунды — по нему видно в overlay, что приложение услышало. **Whisper**
обрабатывает завершённую фразу целиком: расставляет пунктуацию, чинит формы
слов и сохраняет английские термины латиницей. В поле ввода по умолчанию
попадает именно результат Whisper — один раз, после паузы.

## Возможности

- Глобальная горячая клавиша: режим Toggle или push-to-talk.
- `Esc` всегда останавливает диктовку, в любом режиме и в любом приложении.
- Русский и английский язык, выбор по раскладке активного окна.
- Английские термины внутри русской речи остаются латиницей: `Открой GitHub и создай pull request.`
- Пользовательский словарь замен с импортом и экспортом JSON.
- Голосовые команды пунктуации: «точка», «запятая», «новая строка» и другие.
- Ввод через Unicode SendInput — не зависит от текущей раскладки; резервный
  путь через буфер обмена с восстановлением прежнего содержимого.
- Защита пользовательского текста: после ручной правки, смены окна или
  перемещения курсора автоматическая замена запрещается.
- Overlay поверх окон появляется только на время диктовки: состояние, уровень
  сигнала, изменяемый хвост фразы, кнопки остановки, отмены, ручной замены и
  копирования.
- Менеджер моделей: загрузка, проверка, безопасная распаковка.
- Автоматические обновления: проверка при запуске и раз в несколько часов.

## Установка

Скачайте `VoiceFlowWin-Setup-x64-<версия>.exe` со страницы
[Releases](https://github.com/gramotun-droid/voice-flow-win/releases) и
запустите. Установка выполняется для текущего пользователя и не требует прав
администратора.

Портативный вариант: распакуйте `VoiceFlowWin-Portable-x64-<версия>.zip` и
запустите `VoiceFlowWin.exe`.

Проверить целостность загруженных файлов можно по `checksums.txt`.

### Первый запуск

Модели в установщик не входят: весь каталог весит около 2,6 ГБ. После первого
запуска приложение само докачивает недостающие модели в фоне — начиная с
рекомендованных, чтобы диктовка заработала уже после первых сотен мегабайт.
Пока набора не хватает, открыта вкладка **Модели**: там видно, что качается.
Автоматическую загрузку можно выключить там же.

Рекомендованный набор:

| Модель | Назначение | Размер |
| --- | --- | --- |
| Vosk русский, компактная | потоковый ввод на русском | ~45 МБ |
| Vosk английский, компактная | потоковый ввод на английском | ~40 МБ |
| Whisper small, квантованная | финальная обработка фраз | ~190 МБ |

Модели хранятся в `%LocalAppData%\VoiceFlowWin\Models` и переживают
обновление и переустановку приложения.

Скачиваются они с зеркала HuggingFace, а исходные сайты (alphacephei.com и
huggingface.co) остаются запасным источником: у части провайдеров они отдают
около килобайта в секунду. Содержимое сверяется с контрольной суммой SHA-256,
прерванная загрузка продолжается с того же места.

## Использование

1. Установите курсор в любое текстовое поле.
2. Нажмите `Ctrl + F5` (сочетание меняется в настройках).
3. Говорите — распознанное видно в overlay, поле пока не трогается.
4. Замолчите: после паузы фраза целиком вставляется в поле, уже проверенная
   Whisper. Длительность паузы задаётся на вкладке «Микрофон».
5. Нажмите сочетание повторно или `Esc`, чтобы закончить.

Это поведение по умолчанию: приложение ничего не переписывает в чужом поле,
поэтому промежуточная гипотеза в нём не задержится. Если нужен текст прямо во
время речи, на вкладке «Основное» есть режимы потокового ввода — они печатают
по мере распознавания и затем заменяют фразу на исправленную.

Пока приложение печатает, не трогайте текст руками: любая ручная правка,
клик мышью в поле или переключение окна замораживают текущую фразу. Это
сделано намеренно — иначе автоматическое исправление могло бы затереть то,
что вы написали сами. Замороженный результат Whisper показывается в overlay,
откуда его можно применить кнопкой или скопировать.

## Ограничения

- Ввод в окно, запущенное от имени администратора, блокируется Windows (UIPI).
  Чтобы диктовать в такое окно, запустите VoiceFlowWin от администратора.
- В приложениях, игнорирующих синтетический ввод, работает резервный режим
  через буфер обмена — включается автоматически.
- Полный список известных ограничений: [LIMITATIONS.md](LIMITATIONS.md).

## Сборка из исходного кода

Нужен .NET SDK 8.0. Официальные выпуски собираются только на GitHub Actions;
локальная сборка предназначена для разработки.

```bash
dotnet restore VoiceFlowWin.sln
dotnet build VoiceFlowWin.sln --configuration Release

# Кроссплатформенные тесты (проходят и на Linux, и на Windows)
dotnet test tests/VoiceFlowWin.Tests/VoiceFlowWin.Tests.csproj

# Тесты Win32-слоя — только на Windows
dotnet test tests/VoiceFlowWin.Windows.Tests/VoiceFlowWin.Windows.Tests.csproj
```

Собирать выпуск нужно **на Windows**: пакеты Vosk и Whisper.net.Runtime
подкладывают native-библиотеки по операционной системе сборки, а не по
целевому RID. На Linux решение компилируется и проходит тесты, но в каталог
публикации попадут `.so` вместо `.dll`. Поэтому publish и установщик в CI
выполняются на `windows-latest`.

Публикация и установщик (Windows, нужен Inno Setup 6):

```powershell
dotnet publish src/VoiceFlowWin.App/VoiceFlowWin.App.csproj -c Release -r win-x64 --self-contained false -o publish
dotnet publish src/VoiceFlowWin.UpdaterHost/VoiceFlowWin.UpdaterHost.csproj -c Release -r win-x64 --self-contained false -o publish
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" /DMyAppVersion=0.1.0 installer\voiceflowwin.iss
```

Версия задаётся в одном месте — `Directory.Build.props`; при выпуске её
подставляет release-workflow из имени тега.

## Выпуск

Выпуск создаётся пушем тега:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Workflow соберёт приложение, прогонит тесты, создаст установщик, portable-архив,
контрольные суммы, SBOM, список лицензий и `update-manifest.json`, после чего
опубликует GitHub Release.
