## Известные ожидаемые ограничения

- **Окна с повышенными правами.** Windows не даёт обычному процессу отправлять
  ввод в окно администратора. Приложение обнаруживает это заранее и предлагает
  перезапуск, но обойти ограничение нельзя.
- **Позиция каретки.** Определяется через `GetGUIThreadInfo`. Приложения,
  рисующие собственную каретку (часть Electron- и Qt-приложений), могут её не
  публиковать. В таком случае перемещение курсора мышью не будет распознано
  как вмешательство, и защита сработает только по смене окна или по нажатию
  клавиш. Это осознанный компромисс: UI Automation дала бы более точный
  результат ценой заметного расхода CPU на каждый опрос.
- **Максимально живой режим.** Требует удаления собственного хвоста нажатиями
  `Backspace`. Приложения с автодополнением или автозаменой могут отреагировать
  на это непредсказуемо, поэтому по умолчанию включён безопасный режим.

## Как заполнить матрицу

1. Установите сборку из релиза на Windows 10 или 11 x64.
2. Установите рекомендованные модели.
3. Пройдите по каждому приложению список из десяти проверок выше.
4. Замените `?` на «да», «нет» или краткое описание проблемы.
5. Дополните раздел ограничений тем, что обнаружится.
