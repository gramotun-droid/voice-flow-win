# Отчёт о производительности

## Статус: замеры не выполнялись

Ни один показатель из списка ниже не измерен. Причина простая: разработка велась
в окружении без Windows-машины и без микрофона, а Vosk и whisper.cpp работают
через native-библиотеки, которые здесь не запускались. Приводить оценки в
качестве измерений было бы враньём, поэтому таблица оставлена пустой.

## Методика

1. Собрать релизную сборку и установить рекомендованные модели.
2. Включить запись техлога, диктовать заранее подготовленный текст на 5 минут:
   русский, английский, смешанные термины.
3. Задержки снимать по временным меткам лога: кадр захвата → первая гипотеза →
   вставка → результат Whisper.
4. CPU и RAM снимать через `Get-Counter` или диспетчер задач, отдельно в покое,
   при диктовке и при финализации.
5. Повторить на слабой машине (2 ядра) и на обычной (8 ядер).
6. Заполнить колонку «Факт» и приложить исходный лог.

## Что уже сделано для производительности

Эти решения приняты по конструкции, но их эффект не измерен:

- Захват микрофона полностью остановлен вне диктовки — в покое нет ни потока
  аудио, ни работы VAD.
- Модели загружаются один раз и переиспользуются; процесс на фразу не
  запускается.
- Тяжёлые распознавания выполняются строго по одному через очередь.
- Промежуточный результат Vosk опрашивается не чаще заданного интервала.
- Кольцевой буфер имеет фиксированный размер, поэтому память не растёт при
  длинной диктовке.
- Аудио сегмента освобождается сразу после финализации.
- VAD не требует нейросетевой модели: считаются RMS и переходы через ноль.
