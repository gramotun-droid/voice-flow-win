# Приёмка VoiceFlowWin на Windows

Этот протокол отделяет проверки, которые выполняет CI, от пользовательского
пути с настоящим рабочим столом, микрофоном и сторонними приложениями. Релиз
кандидат в beta считается принятым только после заполнения отчёта на Windows
10 и Windows 11 x64.

## 1. Автоматический smoke-test

На чистой копии репозитория откройте Windows PowerShell 5.1 или PowerShell 7:

```powershell
.\scripts\windows-smoke.ps1 -LaunchApplication
```

Скрипт проверит форматирование, Release-сборку, оба набора тестов, настоящий
`win-x64` publish, наличие Windows native-библиотек, цифровые подписи и запуск
приложения. Отчёт сохраняется в `TestResults\windows-smoke.json`.

Контрольный прогон 27 августа 2026 года прошёл на Windows 10 10.0.19045 x64:
163 быстрых core-теста и 19 Windows-тестов успешны, два сетевых модельных теста
штатно пропущены, опубликованное WPF-приложение оставалось запущенным до
автоматического завершения через восемь секунд. Ручная диктовка этим прогоном
не проверялась.

Если установлен Inno Setup 6, дополнительно соберите установщик командой из
README и проверьте его тем же способом:

```powershell
.\scripts\windows-smoke.ps1 -InstallerPath .\installer_output\VoiceFlowWin-Setup-x64-0.3.0-beta.2.exe
```

## 2. Окружение отчёта

Зафиксируйте:

- Windows 10/11 и номер сборки;
- CPU, RAM, модель микрофона и аудиодрайвер;
- версию VoiceFlowWin и SHA-256 установщика;
- выбранные модели и режим ввода;
- обычные или повышенные права целевого приложения.

## 3. Тестовые фразы

Произнесите каждую фразу не менее трёх раз:

1. `Сегодня мы проверяем голосовой ввод, пунктуацию и окончание фразы.`
2. `Открой GitHub, создай pull request и запусти dotnet test.`
3. `Первая строка новая строка вторая строка точка.`
4. Английская: `Please open the settings window and check the microphone.`

Отдельно проверьте непрерывную речь в течение пяти минут и короткие фразы из
одного-двух слов.

## 4. Проверки в каждом приложении

Пройдите Notepad, Word, Chrome, Edge, Telegram Desktop, VS Code, WPF TextBox и
WinForms TextBox:

1. Toggle и push-to-talk запускают и останавливают диктовку.
2. `Esc` останавливает VoiceFlowWin и не закрывает целевое приложение.
3. Русский ввод работает при английской раскладке и наоборот.
4. В режиме по умолчанию поле не меняется до паузы, затем получает целую фразу.
5. Потоковые режимы не дублируют и не теряют слова.
6. После ручного нажатия клавиши, смены окна и перемещения каретки сегмент
   замораживается и пользовательский текст не удаляется.
7. SendInput и принудительный режим буфера обмена работают; прежнее содержимое
   буфера восстанавливается.
8. Overlay не забирает фокус.
9. Финальный проход после остановки не повреждает уже изменённый пользователем
   текст.
10. История при выключенных флагах не создаётся. При включённых появляются
    `history.json` и валидный WAV; «Очистить историю» удаляет оба.

Результаты занесите в [COMPATIBILITY.md](../COMPATIBILITY.md): `да`, `нет` или
краткое описание с номером issue. Не заменяйте `?` ожиданием без фактической
проверки.

## 5. Установка и обновление

1. Установить для текущего пользователя без прав администратора.
2. Проверить подпись в свойствах EXE и отсутствие предупреждения о неизвестном
   издателе для стабильного релиза.
3. Запустить, скачать модели, перезагрузить Windows и проверить автозапуск.
4. Обновиться с предыдущего релиза; настройки, словарь и модели должны остаться.
5. Удалить приложение; пользовательские данные должны остаться до явного
   удаления `%LocalAppData%\VoiceFlowWin`.

## 6. Критерии beta

- нет порчи пользовательского текста ни в одном сценарии;
- нет падений и зависаний за 30 минут смешанной диктовки;
- матрица заполнена хотя бы для Notepad, Chrome, Word, Telegram и VS Code на
  Windows 10 и 11;
- показатели из `docs/PERFORMANCE.md` заполнены фактическими значениями;
- stable-установщик, приложение и updater имеют валидную Authenticode-подпись.
