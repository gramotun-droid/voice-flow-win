# Конфиденциальность

## Коротко

Аудио и распознанный текст не покидают компьютер. Ни то, ни другое по
умолчанию не сохраняется на диск. Телеметрии нет.

## Что происходит со звуком

Микрофон записывается только во время активной диктовки — между сеансами
захват остановлен, а не приглушён. Звук живёт в оперативной памяти:

- кольцевой буфер хранит последние доли секунды для pre-roll и очищается
  при остановке;
- аудио сегмента передаётся Zipformer и Whisper; до конца сеанса оно также
  может находиться в памяти для опционального финального прохода;
- на диск звук записывается только если одновременно включены «Вести историю
  диктовок» и «Сохранять WAV-запись сеанса в истории». WAV лежит в
  `%LocalAppData%\VoiceFlowWin\HistoryAudio` и удаляется вместе с записью
  после заданного срока хранения.

## Что происходит с текстом

Распознанный текст вставляется в активное поле и хранится в памяти до конца
сеанса диктовки — он нужен, чтобы исправлять только собственные символы. По
завершении сеанса эти данные очищаются.

История диктовок по умолчанию отключена. Если включить её в настройках,
метаданные хранятся локально в `%LocalAppData%\VoiceFlowWin\history.json`
заданное число дней. Сам распознанный текст включается в запись только при
отдельном согласии «Включать распознанный текст в историю». Удалить JSON и
все связанные WAV можно кнопкой «Очистить историю».

## Сетевые обращения

Приложение выходит в сеть в трёх случаях, и все они инициируются
пользователем или его настройками:

| Когда | Куда | Что передаётся |
| --- | --- | --- |
| Загрузка модели в менеджере моделей | GitHub Releases sherpa-onnx, зеркало или origin Hugging Face | обычный HTTPS-запрос файла |
| Проверка обновлений | `update-manifest.json` в GitHub Releases | версия не передаётся, запрос анонимный |
| Резервная проверка обновлений | GitHub Releases API | запрос анонимный, без токена |

Ни аудио, ни текст, ни сведения о том, где и что вы диктуете, никуда не
отправляются. Облачного распознавания в приложении нет.

## Логи

Технический лог (`%LocalAppData%\VoiceFlowWin\Logs`) содержит состояния,
длительности, размеры результатов и ошибки: смену состояния диктовки, причину
заморозки сегмента, сбои загрузки моделей. Содержимое диктовки, контекст
Whisper, вставляемые и заменяемые строки в лог не записываются.

## Что приложение видит, но не сохраняет

Чтобы не испортить ваш текст, VoiceFlowWin отслеживает активное окно, элемент
ввода и положение каретки, а также факт нажатия клавиш во время диктовки.
Эти данные используются только для принятия решения «можно ли править текст»
и никуда не записываются: в памяти держатся дескриптор окна, имя процесса и
координаты каретки текущего сегмента.

Низкоуровневый клавиатурный хук активен только во время диктовки и во время
назначения горячей клавиши. Он проверяет код клавиши и не накапливает ввод.

## Права администратора

Приложение не запрашивает повышенные права. Если целевое окно запущено от
администратора, Windows блокирует ввод (UIPI) — вместо обхода этого
ограничения приложение показывает уведомление и предлагает перезапуск.

## Удаление данных

- «Открыть папку данных» в настройках — прямой доступ ко всему, что хранится.
- «Очистить историю» — удаление истории диктовок.
- Полное удаление: удалите каталог `%LocalAppData%\VoiceFlowWin` после
  деинсталляции. Деинсталлятор сознательно оставляет его, чтобы переустановка
  не заставляла заново скачивать модели и терять словарь.
