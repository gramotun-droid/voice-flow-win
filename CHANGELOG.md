# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [Не выпущено]

## [0.3.0] — 2026-09-09

### Изменено

- Возможности, проверенные в серии `0.3.0-beta`, переведены в стабильный канал.
- Стабильный выпуск допускается без сертификата по явному решению владельца;
  манифест помечает его как `unsigned`, а updater обязательно проверяет размер
  и SHA-256 установщика перед запуском.

## [0.3.0-beta.8] — 2026-09-09

### Исправлено

- Индикатор микрофона теперь находит каретку не только через Win32, но и через
  Windows UI Automation. Это добавляет поддержку браузеров, Electron и других
  приложений с собственной отрисовкой каретки; при отсутствии точного текстового
  диапазона индикатор показывается у активного поля ввода.

## [0.3.0-beta.7] — 2026-09-09

### Добавлено

- Рядом с системной текстовой кареткой во время диктовки показывается
  неактивируемый и прозрачный для кликов значок микрофона. В ожидании речи он
  зелёный, во время распознавания — синий и пульсирующий; индикатор можно
  отдельно отключить в настройках.

### Исправлено

- Голосовые команды «точка», «запятая», «двоеточие», «тире» и «точка с
  запятой» заменяются в живой гипотезе без оставшегося перед знаком пробела;
  также поддерживается вариант «точка запятой».
- Команда «с новой строки» сохраняется нормализатором и отправляет настоящее
  нажатие Enter, поэтому действительно переносит каретку в активном поле.
- Переключатель голосовых команд теперь применяется непосредственно при
  обработке каждой потоковой гипотезы.

## [0.3.0-beta.6] — 2026-09-07

### Исправлено

- Beta-канал теперь ищет prerelease в полном списке GitHub Releases до чтения
  stable-манифеста из `releases/latest` и использует полноценный манифест
  выбранного beta-релиза для безопасной автоматической загрузки.
- «Проверить сейчас» сразу учитывает канал, выбранный в открытом окне настроек,
  даже если общая кнопка «Сохранить» ещё не была нажата.
- Числовые части prerelease сравниваются по SemVer: `beta.10` корректно
  считается новее `beta.9`.

## [0.3.0-beta.5] — 2026-09-07

### Изменено

- Финальное распознавание Whisper удалено из рабочего пути: приложение
  использует только текущую гипотезу Zipformer, сразу печатает её целиком и не
  заменяет набранный текст после паузы или остановки.
- Автоматически скачиваются только русская и английская потоковые модели;
  прежние настройки режимов ввода переводятся на единый живой набор.
- Пауза завершения речевого фрагмента зафиксирована на 5 секундах. При
  обновлении прежнее сохранённое значение переносится автоматически, после
  закрытия фрагмента диктовка продолжает слушать следующий.

### Добавлено

- Опциональная локальная история диктовок с атомарным `history.json`,
  сохранением WAV, сроком хранения и полной очисткой из настроек.
- Еженедельная и ручная интеграционная проверка загрузки настоящих моделей и
  потокового распознавания в GitHub Actions.
- Воспроизводимые сценарии Windows smoke-тестирования и сбора показателей
  производительности.
- Лицензия MIT для исходного кода проекта.

### Исправлено

- Последнее слово больше не остаётся серым и невведённым, а остановка
  диктовки синхронно закрепляет текущий сегмент до очистки сеанса.
- При ошибке повторной печати после уточнения гипотезы приложение пытается
  восстановить только что удалённый собственный хвост.
- Распознанный, вставленный и исправленный текст больше не записывается в
  технический лог; журнал содержит только длины и состояния обработки.
- Интеграционный тест загрузки обновлён с удалённой Vosk-модели на актуальную
  английскую модель Zipformer.
- Версия сборки и файлов синхронизируется с SemVer релизного тега.
- Стабильный релиз требует сертификат подписи; при его наличии подписываются
  приложение, updater и установщик.

## [0.2.4] — 2026-08-06

### Изменено

- Потоковое распознавание переведено с Vosk на sherpa-onnx (Zipformer,
  transducer). Русская модель стала вдвое меньше — 24 МБ против 45 — и
  работает без словарной решётки, английская сменилась на компактную 20M.
  Пути к прежним моделям очищаются при обновлении: новые скачиваются сами.

### Добавлено

- Проход по всей диктовке после остановки: Whisper получает запись целиком и
  согласует между фразами пунктуацию и формы слов, чего пофразная обработка
  сделать не может. Пока проход идёт, системный курсор показывает занятость —
  правка текста в этот момент отменила бы замену. Отключается на вкладке
  «Распознавание».
- Гибридное распознавание: потоковый Zipformer для текста во время речи и
  whisper.cpp для финальной перепроверки завершённой фразы.
- Глобальная горячая клавиша в режимах Toggle и push-to-talk, по умолчанию
  `Ctrl + F5`; сочетание хранится кодом клавиши и не зависит от раскладки.
- Остановка диктовки клавишей `Esc` в любом режиме, с выбором «сохранить
  распознанное» или «отменить сегмент» и подавлением нажатия, чтобы не
  закрылось окно активного приложения.
- Защита пользовательского текста: заморозка сегмента при ручной правке,
  смене окна, смене элемента ввода, перемещении каретки, вставке из буфера
  и отмене действия.
- Ввод текста через Unicode SendInput с резервным путём через буфер обмена и
  восстановлением прежнего содержимого.
- Выбор языка по раскладке активного окна, режимы «всегда русский», «всегда
  английский» и автоопределение Whisper.
- Пользовательский словарь замен с вариантами произношения, импортом и
  экспортом JSON и набором терминов по умолчанию.
- Голосовые команды пунктуации и правки текста.
- Overlay поверх окон: состояние, уровень сигнала, язык, стабильный текст,
  изменяемый хвост, предупреждение о вмешательстве и кнопки остановки,
  отмены, ручной замены и копирования. Окно видно только во время диктовки,
  а также пока не разобран замороженный результат или ошибка.
- Пути к скачанным моделям сохраняются сразу и сверяются с каталогом моделей
  при запуске: скачанная модель работает без нажатия «Сохранить», а удалённая
  не оставляет нерабочий путь.
- Недостающие модели докачиваются автоматически после запуска, по одной и
  начиная с рекомендованных; загрузку можно выключить на вкладке «Модели».
- Режим по умолчанию: пока идёт речь, поле ввода не трогается, а после паузы
  фраза вставляется целиком и уже проверенной Whisper. Промежуточные гипотезы
  видны только в overlay, приложение ничего не переписывает в чужом поле.
  Прежние потоковые режимы остались на вкладке «Основное».
- Окончание фразы больше не пропадает. Пустой финальный результат потоковой модели —
  обычное дело, но он отбрасывал изменяемый хвост, который в безопасном режиме
  виден только в overlay. Вторая причина та же, что у ложной ручной правки:
  помеченный сегмент молча отказывался печатать что-либо ещё.
- Язык фразы определяется по окну, в которое идёт диктовка, а не по overlay:
  overlay появляется ровно в момент старта, и снимок фокуса мог попасть на
  него — русская речь уходила в Whisper как английская.
- После установки обновления приложение снова запускается само: Inno Setup
  продолжает работу во временном процессе, поэтому запуск происходил поверх
  ещё идущей установки, и установщик тут же закрывал приложение.
- Непрерывная диктовка больше не выставляет себе признак ручной правки:
  позиция каретки считается по её экранным координатам и меняется от каждого
  напечатанного символа, а ожидаемое значение обновлялось с опозданием.
- Команды пунктуации на русском срабатывают и в окнах с английской
  раскладкой: язык сегмента определяется по раскладке, а говорить по-русски
  в таком окне — обычное дело.
- Загрузка с источника, отдающего медленнее 16 КБ/с, прерывается вместо
  бесконечного ожидания.
- Модели Whisper качаются с зеркала с запасным переходом на исходный сайт:
  у части провайдеров huggingface.co отдаёт около килобайта в секунду. Загрузка продолжается с прерванного места, обрывается по таймауту
  молчания, повторяется до трёх раз на источник, а содержимое сверяется с
  контрольной суммой SHA-256. В индикаторе видно объём и скорость.
- Тёмная тема окна настроек доведена до конца: вкладки, кнопки, списки,
  выпадающие списки и таблица словаря больше не рисуются светлым по светлому.
- Окно настроек по всем разделам: основное, микрофон, модели, распознавание,
  вставка текста, словарь, конфиденциальность, обновления.
- На вкладке «Распознавание» модель выбирается списком скачанных моделей, а не
  вводом пути; путь показывается под списком. Список и поля обновляются, когда
  модель докачалась в фоне.
- Менеджер моделей с загрузкой, прогрессом, отменой, проверкой контрольной
  суммы и безопасной распаковкой без выхода за пределы каталога.
- Служба обновлений: проверка при запуске и раз в несколько часов, каналы
  Stable и Beta, автоматическая загрузка, докачка по HTTP Range, обязательная
  проверка SHA-256 до запуска, кнопки «Обновить сейчас» и «Позже», отдельный
  процесс установки.
- Значок в трее с отражением состояния и single instance.
- CI на GitHub Actions: тесты на Linux, тесты Win32-слоя, publish и сборка
  установщика на Windows.
- Release-workflow: установщик, portable-архив, контрольные суммы, SBOM,
  список лицензий, `update-manifest.json` и публикация GitHub Release по тегу.

### Известно

- Приложение ни разу не запускалось на Windows: ручное тестирование и замеры
  производительности не выполнялись. Подробности — в
  [LIMITATIONS.md](LIMITATIONS.md), [COMPATIBILITY.md](COMPATIBILITY.md) и
  [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
