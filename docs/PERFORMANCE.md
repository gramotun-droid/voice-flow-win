# Отчёт о производительности

## Статус: измерен только покой без моделей

27 августа 2026 года опубликованное приложение измерено на Windows 10
10.0.19045 x64 в течение 10 секунд после запуска, без загруженных моделей и
активной диктовки. Средняя и пиковая загрузка CPU округлились до 0,00%, средний
и пиковый working set составили 41,52 МиБ. Это базовый idle-показатель, а не
оценка распознавания; без реального микрофона остальные значения оставлены
пустыми.

| CPU при диктовке | Zipformer + VAD на потоке 16 kHz | зависит от CPU и модели | не измерено |

## Методика

1. Собрать релизную сборку и установить рекомендованные модели.
2. Включить запись техлога, диктовать заранее подготовленный текст на 5 минут:
   русский, английский, смешанные термины.
3. Задержки снимать по временным меткам лога: кадр захвата → первая гипотеза →
   вставка → результат Whisper.
4. CPU и RAM снимать через `Get-Counter` или диспетчер задач, отдельно в покое,
   при диктовке и при финализации.
5. Повторить на слабой машине (2 ядра) и на обычной (8 ядер).
6. Заполнить колонку «Факт» и приложить исходный лог.

Для воспроизводимого сбора CPU и RAM запустите на Windows:

```powershell
.\scripts\collect-performance.ps1 -DurationSeconds 300
```

Скрипт пишет CSV с секундными выборками и краткую сводку рядом с ним. Задержку
первого текста и качество распознавания всё равно нужно отмечать вручную по
сценарию из [WINDOWS_VALIDATION.md](WINDOWS_VALIDATION.md): автоматический
раннер без микрофона не может честно измерить пользовательский путь.

## Что уже сделано для производительности

Эти решения приняты по конструкции, но их эффект не измерен:

- Захват микрофона полностью остановлен вне диктовки — в покое нет ни потока
  аудио, ни работы VAD.
- Модели загружаются один раз и переиспользуются; процесс на фразу не
  запускается.
- Тяжёлые распознавания выполняются строго по одному через очередь.
- Промежуточный результат Zipformer опрашивается не чаще заданного интервала.
- Кольцевой буфер имеет фиксированный размер, поэтому память не растёт при
  длинной диктовке.
- Аудио сегмента освобождается сразу после финализации.
- VAD не требует нейросетевой модели: считаются RMS и переходы через ноль.
