# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Гибридное распознавание: потоковый Vosk для текста во время речи и
  whisper.cpp для финальной перепроверки завершённой фразы.
- Глобальная горячая клавиша в режимах Toggle и push-to-talk, по умолчанию
  `Ctrl + Alt + Space`; сочетание хранится кодом клавиши и не зависит от
  раскладки.
- Остановка диктовки клавишей `Esc` в любом режиме, с выбором «сохранить
  распознанное» или «отменить сегмент» и подавлением нажатия, чтобы не
  закрылось окно активного приложения.
- Защита пользовательского текста: заморозка сегмента при ручной правке,
  смене окна, смене элемента ввода, перемещении каретки, вставке из буфера
  и отмене действия.
- Ввод текста через Unicode SendInput с резервным путём через буфер обмена и
  восстановлением прежнего содержимого.
- Выбор языка по раскладке активного окна, режимы «всегда русский», «всегда
  английский» и автоопределение Whisper.
- Пользовательский словарь замен с вариантами произношения, импортом и
  экспортом JSON и набором терминов по умолчанию.
- Голосовые команды пунктуации и правки текста.
- Overlay поверх окон: состояние, уровень сигнала, язык, стабильный текст,
  изменяемый хвост, предупреждение о вмешательстве и кнопки остановки,
  отмены, ручной замены и копирования.
- Окно настроек по всем разделам: основное, микрофон, модели, распознавание,
  вставка текста, словарь, конфиденциальность, обновления.
- Менеджер моделей с загрузкой, прогрессом, отменой, проверкой контрольной
  суммы и безопасной распаковкой без выхода за пределы каталога.
- Служба обновлений: проверка при запуске и раз в несколько часов, каналы
  Stable и Beta, автоматическая загрузка, докачка по HTTP Range, обязательная
  проверка SHA-256 до запуска, кнопки «Обновить сейчас» и «Позже», отдельный
  процесс установки.
- Значок в трее с отражением состояния и single instance.
- CI на GitHub Actions: тесты на Linux, тесты Win32-слоя, publish и сборка
  установщика на Windows.
- Release-workflow: установщик, portable-архив, контрольные суммы, SBOM,
  список лицензий, `update-manifest.json` и публикация GitHub Release по тегу.

### Известно

- Приложение ни разу не запускалось на Windows: ручное тестирование и замеры
  производительности не выполнялись. Подробности — в
  [LIMITATIONS.md](LIMITATIONS.md), [COMPATIBILITY.md](COMPATIBILITY.md) и
  [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
